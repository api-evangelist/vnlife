# VNLIFE / VNPAY

> VNLIFE is the Vietnamese technology and financial-services holding group behind VNPAY (Vietnam Payment Solution JSC), the leading electronic-payment provider in Vietnam. Its flagship is the VNPAY-QR payment gateway — a redirect + IPN HTTP API secured with HMAC-SHA512 checksums, supporting QR, domestic ATM/bank-account, international card, tokenization and installment payments across 40+ banks and 15+ e-wallets. Backed by SoftBank Vision Fund and GIC.

## APIs

- [VNPAY Payment Gateway (developer portal)](https://sandbox.vnpayment.vn/apis/): vpcpay redirect + IPN + merchant web API (query/refund).
- [Payment integration reference](https://sandbox.vnpayment.vn/apis/docs/thanh-toan-pay/pay.html): vnp_ parameters, HMAC-SHA512 vnp_SecureHash, Return/IPN flow, response codes.
- [Sandbox / try it now](https://sandbox.vnpayment.vn/tryitnow/Home/CreateOrder): hosted test order creator with published test cards.
